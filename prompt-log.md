# Prompt Log - Modul 6 KlubKita

## Tujuan
Konversi desain KlubKita menjadi HTML5 semantik tanpa CSS atau styling.

## Aturan yang diterapkan
- Tidak menggunakan file CSS.
- Tidak menggunakan tag <style>.
- Tidak menggunakan atribut style="".
- Tidak menggunakan Bootstrap atau Tailwind.
- Mengutamakan header, nav, main, section, article, aside, footer.
- Menggunakan heading secara berurutan.
- Menghubungkan label dan input dengan for/id.
- Menggunakan form, fieldset, legend, input, button.
- Menggunakan path gambar relatif ./assets/images/.
- Memberikan alt pada gambar informatif.
- Menghindari div berlebihan.
- Menjaga alur antarhalaman sesuai wireframe.
